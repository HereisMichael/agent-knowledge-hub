# Hermes Gateway

单进程 Gateway 连接多 IM 平台，支持 **跨端续聊**（Telegram 开始、CLI 继续）。

## 配置

`hermes setup` 交互配置渠道与模型；可 systemd 常驻。

## 与售前场景

销售/SA 在外场用手机提问，Agent 在服务器执行查文档、跑脚本，结果推回 IM。
