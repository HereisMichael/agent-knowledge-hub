# Agent 术语表

- **Gateway**：消息与会话控制面
- **Skill**：任务级指令包（常含 SKILL.md）
- **MCP**：模型上下文协议，标准化工具接入
- **ReAct**：推理与行动交替的 Agent 循环
- **Harness**：围绕模型的编排与治理层
- **Eval Harness**：自动化评测与 CI 门禁
- **RAG**：检索增强生成
